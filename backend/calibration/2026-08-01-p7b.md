## 3. 结论

1. **b6c96 五个档位全部超出扫描范围（让 2 子仍 100% 全胜），无均势点**。
   纯 visits 无法把 KataGo 网络的棋力压到"人类低级"区间——policy 基本棋感远超同标签人类，
   印证「调 visits 只能降算力深度、模拟不出人类低级错误模式」。
2. **am3d 上限假设未证伪也未证实**（5400v 强于 rank_3d+2 子，上限可能更高）；现行 maxStrength=am3d
   保守合理，维持 `shared/ai-strength.json` 不变。
3. **WASM 档位标签处置**：由抽象词（入门/简单/标准/困难/大师）改为**具体级别**（约业余 18 级 /
   约业余 10 级 / 约业余 4 级 / 约业余 1 段 / 约业余 3 段），保留"约"前缀——
   实测显示实际棋力只强不弱（每个档位均超过对应 rank + 2 子），精确映射需更高让子扫描
   （让 5~7 子）或错误注入（KaTrain 式，参考 `backend/calibration/README.md` §2.4 思路）。
4. **建议（后续可选）**：低档位若需精确"具体级别"棋力，应引入错误注入
   （强引擎高 visits + 按等级概率替换选点），而非继续压 visits。
   **（2026-08 已落地并演进）**：
   - 初版：KaTrain 盲注式错误注入实现于 `frontend/src/lib/rankInjection.ts`，
     WASM 简化档（wasmGroups 5 档）genmove 启用（见 README §2.4），标签去"约"；
   - 演进：wasmGroups 删除，**WASM 19 路对弈档位扩展为 am20k~am5d 全部等级**
     （kyuRank 由档位 id 推导，上限 5 段 = KaTrain OGS 校准可靠范围；
     b6c96 `maxStrength` am3d→am5d）；对弈档位统一低搜索量（32v）+ `maxTime` 兜底，
     任意档位每手约 5~11s；benchmark 改差分测速修正 visits/s 口径（见 README §2.5）；
   - P7a 全档扫描验证为遗留可选后续。
